# 🍽️ QuickDine – Restaurant Table Booking Platform

QuickDine is a modern, premium restaurant table booking and reservation platform designed to provide a seamless dining experience for customers, restaurant owners, and administrators.

🌐 **Live Website:** https://quickdine-5nl.pages.dev/

💻 **GitHub Repository:** https://github.com/erkuldeepkushwah/quickdine

---

## ✨ Features

### 👤 For Diners

- Browse restaurants and dining venues
- Search and filter restaurants
- Filter by location
- Filter by cuisine
- Filter by price range
- Filter by rating
- Check table and seat availability
- Select reservation date and time
- Select occasion
- Add special dining requests
- Book restaurant tables
- Track active reservations
- Cancel reservations

### 🏪 For Restaurant Owners

- Register a restaurant
- Manage restaurant profile
- Manage restaurant information
- Manage table availability
- View incoming reservations
- Confirm reservations
- Cancel reservations

### 🛡️ For Administrators

- Approve restaurant registrations
- Manage restaurants
- Monitor platform activity
- Monitor system-wide metrics
- Manage application data
